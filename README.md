# Agent Field Notes

一条从 LLM 基础到 LangChain、LangGraph 与生产级 AI Agent 的系统学习路线。

## 在线学习

GitHub Pages: https://serendipity-zsh.github.io/ai-agent-learning/

## 学习方式

- 每个模块先读概念，再完成动手练习。
- 用 trace、日志和测试样例观察过程，不只看最终答案。
- 每完成一个模块，在网页上勾选进度，并把实验记录写入自己的 notes/ 目录。

## 课程模块

1. LLM 应用基础
2. Prompt Engineering
3. Retrieval 与 RAG
4. Agent 与工具
5. Memory 与 State
6. LangChain
7. LangGraph
8. Context / Loop / Graph Engineering
